# Legacy

**A tribute to the glossy smartphone era (2007–2012) that runs in your browser.**
عِش زمن الأجهزة الكلاسيكية من جديد — اختر جهازك وابدأ.

Pick one of four classic devices and use it like the real thing: boot it, slide to unlock, open apps, hear the clicks.

## Features

- **4 devices**, drawn entirely in CSS: Classic (2007), 3G (2008), Four (2010) and Five (2012, taller screen). Each has working Home, Sleep, Volume and Ring/Silent buttons, plus colour finishes.
- **System UI**: boot screen, lock screen with *slide to unlock* and a camera grabber, glossy icons with badges, a dock shelf with reflections, wiggle-to-edit with drag-to-rearrange and delete, folders that open on linen, Spotlight, Notification Center, the multitasking tray, banners, a volume HUD, and incoming and outgoing calls.
- **21 working apps**: Phone (DTMF keypad), Messages (on-screen keyboard and replies), Mail, Browser, Music (a generative music player), Calendar, Photos, Camera (iris shutter, real webcam), Weather (card flip), Clock (world clock, alarm, stopwatch, timer with picker wheels), Notes, Reminders, Calculator, Compass, Voice Memos (VU meter, real recording), Contacts, Stocks, Arcade (Bricks), Sound Lab, Settings (ringtones, wallpapers, brightness) and About.
- **Sound**: every click, chime, ringtone and song is synthesized live with the Web Audio API. The page loads no audio files.
- **Graphics**: every icon, wallpaper, texture (linen, leather, paper) and photo is generated with SVG and canvas. The page loads no image files.

### Keyboard shortcuts

| Key | Action |
| --- | --- |
| `H` | Home (press twice for multitasking) |
| `L` | Sleep / wake |
| `N` | Notification Center |
| `↑` / `↓` | Volume |
| `Space` | Unlock |

## Run

This is a static site with no build step. Open `index.html` or serve the folder with any static host. GitHub Pages works too: go to **Settings → Pages → Deploy from branch → main / root**.

## About originality

Legacy is an independent fan project. It does **not** include or redistribute any manufacturer's icons, wallpapers, fonts, ringtones, logos or firmware. All artwork and all music are original, and the device frames are generic designs inspired by that period.

### Reference material (for study only)

- [Legacy iOS UI Kit (Figma Community)](https://www.figma.com/community/file/1405594264448489514/legacy-ios-ui-kit): a design reference for the era's layout, spacing and controls.
- [NyanSatan/SundanceInH2A](https://github.com/NyanSatan/SundanceInH2A): tools for running real iOS 6 on an iPod touch 3G or the original iPad. It needs real hardware plus official firmware files, so it can't run in a browser and isn't part of this project.
